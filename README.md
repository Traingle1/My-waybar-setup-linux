# My-waybar-setup-linux
I use cachyOS Btw (UwU)

This is my waybar setup. I recommend using Hyprland 
You can download it in arch linux based distro's or arch itself
using :
  sudo pacman -S hyprland waybar

if you want to delete it you can simply: 
  sudo pacman -Rns hyprland waybar
